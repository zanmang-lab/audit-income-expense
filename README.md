# 수입지출내역서 자동 작성

학생회 감사 자료용 **수입지출내역서**를 엑셀 장부·연체료/환불 목록·연체료 규정 텍스트에서 자동 생성하는 도구입니다.

- **웹 UI**: 브라우저에서 파일 업로드 → 사업별 HWP/HWPX + 검수목록 zip 다운로드
- **CLI**: `input/` 폴더 + `config/학기설정.json`으로 로컬 일괄 처리

## 요구 사항

| 항목 | 웹 | CLI |
|------|----|-----|
| OS | Windows (HWP 변환 시) | Windows 권장 |
| Python | **3.10+ 64비트 권장** | 동일 |
| 한글(아래아한글) | HWP 업로드·변환 시 필요 | HWP 출력 시 필요 |
| HWPX 양식 | 사용자 업로드 | `templates/수입지출내역서_양식.hwpx` 배치 |

> 32비트 Python에서도 동작하지만, OCR·한글 연동은 64비트 환경을 권장합니다.

### 처음 쓰는 사람

첫 화면에 기본값(사업 목록, 연체료 규정, 책임자 소속·직위, 사물함 문구)이 미리 들어 있습니다. 학기는 비어 있으니 직접 고릅니다.

1. **① 학기**를 고르면 `26-2`처럼 통합본 표기로 정해집니다. 책임자 성명·연락처(`010-1234-5678`)를 적습니다.
2. **② 사업개요**(`번호. 사업명`, 번호 = 장부 B열 사업번호)와 **③ 연체료 규정** 표에서 이번 학기에 바뀐 것만 고칩니다. 고른 학기와 사업명의 `N학기`가 다르면 알려 줍니다(버튼을 눌러야 바뀜).
3. **④~⑦ 파일 4개**를 올리고 생성하기.

**인계**: 결과 zip에 그때 쓴 `설정.json`이 자동으로 들어갑니다. 다음 담당자는 첫 화면의 "설정.json 불러오기"로 지난 학기 상태에서 시작하면 됩니다(파일을 직접 열어 고치지 않음). 기타 문구와 비고 문장 규칙(관리자용)은 바뀐 경우에만 엽니다.

### 업로드 항목

0. **기본 정보 (선택)** — 학기명(결과 파일 이름 앞에 붙음), 작성자 성명·직위·소속·연락처, 사물함 비고 문구, 필름 1장 가격. 비워 두면 기존 기본값을 씁니다.
1. **수입지출 양식** — `.hwpx` 권장 (`.hwp`는 한글+pyhwpx로 자동 변환)
2. **사업개요** — `번호. 사업명` 형식 텍스트
3. **연체료 규정** — `1DAY ₩1,000: 물품명` 형식 텍스트
4. **장부** / **연체료목록** / **환불자목록** — `.xlsx`

**생성하기**를 누르면 바로 zip이 나오지 않고 **미리보기**가 먼저 나옵니다.

- 페이지별 사업번호·날짜·세목·금액·비고와 검수 항목을 한 화면에서 봅니다. "검수필요 페이지만 보기"로 걸러 볼 수 있습니다.
- **구분·내용·비고**는 그 자리에서 고칠 수 있습니다. 세목과 금액은 장부 그대로이며, 바꾸려면 엑셀을 고쳐 다시 올립니다.
- **이대로 문서 만들기** → 결과 화면에서 zip 다운로드. 결과 화면의 "미리보기로 돌아가 다시 고치기"로 몇 번이든 고쳐 다시 만들 수 있습니다(미리보기는 약 30분 유지).
- 고친 칸은 `검수목록.txt`에 `직접수정: 사업2 / 1페이지 '비고'…`로 남습니다(감사 기록).
- **자동처리(파란 표시)**: 프로그램이 장부·목록을 바탕으로 계산하거나 바꿔 적은 곳입니다. 미리보기 각 쪽, 결과 화면, `검수목록.txt`의 "■ 자동처리" 묶음에 근거와 함께 남습니다. 틀릴 수 있으니 한 번씩 확인하세요.
  - 연체일수(연체료 ÷ 규정 1일 단가), 필름 장수(금액 ÷ 1장 가격), 대납 연결(목록 비고의 "OOO'으로 입금"), 띄어쓰기만 다른 이름 연결
  - 환불 수수료 분리: 페이지의 모든 행에서 "장부 금액 − 환불자 목록 금액"이 같은 양수일 때만 원금 줄 + `수수료 n × 금액` 줄로 나눕니다. 총액은 그대로이고, 검산이 안 되면 나누지 않고 알립니다.
  - 쪽 나눔: 날짜·구분이 같아도 개요가 바뀌면, 일반 사업은 거래처(기재내용)가 바뀌어도 새 쪽으로 나눕니다(사물함·대여 사업은 이름이 매번 달라 거래처로 나누지 않음).
  - 글자로 적힌 날짜·금액을 바꿔 읽은 행
- 장부와 목록의 이름이 띄어쓰기만 다르면(`김 철수`/`김철수`) 같은 사람으로 보고 검수권장으로 알립니다. 찾지 못한 이름은 `비슷한 이름: 김철쑤`처럼 후보를 보여 줍니다(자동으로 고르지는 않음).

결과 zip에는 사업별 문서, `검수목록.txt`, `연체료규정_추출.json`, `설정.json` 등이 포함됩니다.

### 다른 양식 쓰기

- 양식의 칸은 라벨로 확인합니다. 지금 쓰는 학복위 양식은 예전과 똑같은 칸에 채웁니다.
- 줄이 추가되거나 칸 배치가 다른 양식이면 `사업번호`·`사업명`·`날짜`·`수입/지출`·`구분`·`내용`·`총액`·`비고` 라벨의 **바로 오른쪽 칸**에, `세목`·`수량`·`단가` 머리줄 아래 칸에 채웁니다. 다른 이름(`합계`, `일자`, `품목` 등)도 일부 알아봅니다(`src/template_layout.py`).
- **한 페이지 세목 줄 수는 양식에서 셉니다.** 세목 칸이 10줄인 양식이면 10줄마다 페이지를 나눕니다.
- 필요한 칸을 찾지 못하면 문서를 만들지 않고 어떤 칸이 없는지 알려 줍니다. 라벨을 확인하지 못해 기존 위치에 채운 칸이나, 값을 넣지 못한 칸은 검수목록에 남습니다.

### 설정 파일과 비고 규칙

- 첫 화면 **설정 파일 → 현재 입력으로 저장**을 누르면 사업개요·연체료 규정·기본 정보·비고 규칙이 `수입지출_설정_학기명.json` 한 파일로 저장됩니다. 다음 학기나 다음 담당자는 **불러오기**만 하면 입력칸이 채워집니다. 결과 zip에도 그때 쓴 설정이 `설정.json`으로 들어 있습니다. 연락처는 넣지 않습니다.
- **사업 종류**는 사업개요 줄 끝에 `[사물함]`·`[대여]`·`[학생회비]`·`[일반]`을 붙여 직접 정할 수 있습니다. 붙이지 않으면 사업명 키워드(비고 규칙의 `사업종류_키워드`)로 정합니다.
- **비고 규칙(고급)** 칸에서 아래를 바꿀 수 있습니다. 바꾸고 싶은 항목만 남겨도 되고, 없는 항목은 기본값을 씁니다. 기본값은 이전 버전과 같은 문장을 만듭니다.

| 항목 | 내용 |
|------|------|
| `비고문장` | 연체·필름값·손망실비·감면·환불 문장 틀. 예: `"{대상} {물품} 대여 후 {일수}일 연체되어 연체료 {금액}원 부과"` |
| `환불페이지_키워드` | 개요에 이 말이 있으면 환불 페이지로 봄 (기본 `환불`) |
| `환불사유_표현` | 환불자 목록 사유 → 비고 표현 (띄어쓰기 무시). 예: `"두번송금": "두 번 송금"` |
| `환불사유_묶음` | 같은 사유가 여러 명일 때 묶어 쓰는 방식 |
| `연체료비고_분류` | 연체료목록 비고가 이 말이면 필름값·손망실비·감면으로 처리 (띄어쓰기 무시) |
| `사업종류_키워드` | 사업명에 이 말이 있으면 해당 종류로 봄 |
| `환불수수료_안내` | 사물함 환불 페이지에 붙는 검수권장 문구 |

  문장 틀에 쓸 수 없는 칸을 넣거나 JSON 형식이 틀리면, 어느 줄·어떤 칸이 문제인지 알려 주고 문서를 만들지 않습니다.
- 대납 비고는 `백서준'으로 입금` 외에 `백서준으로 입금`(따옴표 없음), `백서준 충당`도 인식합니다.
- CLI는 `config/학기설정.json`에 `"비고규칙": { ... }`을 넣으면 같은 규칙을 씁니다. `businesses`의 `role`에는 `사물함`/`대여`/`학생회비`/`일반`(또는 영문 locker/rental/student_fee/general)을 쓸 수 있습니다.

### 엑셀을 읽는 방식

- **열은 헤더 이름으로 찾습니다.** 열 순서가 달라도, 다른 열(현금·메모 등)이 끼어 있어도 됩니다. 헤더가 맨 윗줄이 아니어도 위쪽 10줄 안이면 찾습니다.
  - 장부 필수: 날짜 · 사업번호 · 기재내용(세목) · 수입 · 지출 / 선택: 세부번호 · 구분 · 개요 · 오류여부
  - 연체료목록 필수: 대여물품 · 성명(이름) · 연체료 / 선택: 반납일 · 비고
  - 환불자목록 필수: 이름(성명) · 사유 / 선택: 사물함 번호 · 환불금액
  - 받아들이는 다른 이름은 `src/sheet_reader.py`의 열 정의에 있습니다.
- 헤더를 하나도 알아보지 못하면 예전 열 순서(A~J)로 읽고 그 사실을 알려 줍니다. 필수 열 일부만 없으면 추정하지 않고 어떤 열이 없는지 오류로 알려 줍니다.
- 날짜는 엑셀 날짜, `2026-03-05`, `2026.3.5.`, `2026년 3월 5일`을 읽습니다. 연도가 없는 `3/5`는 추정하지 않습니다. 금액은 `4,000`, `4,000원`도 읽습니다.
- 읽지 못했거나 제외한 행(날짜·사업번호를 못 읽음, 음수 금액, 한 행에 수입·지출이 함께 있음 등)은 결과 화면의 **입력 파일 확인**과 `검수목록.txt` 맨 위에 `[입력확인] 장부 34행: …` 형식으로 나옵니다. 이 행들은 결과 문서에 빠져 있으니 엑셀을 고친 뒤 다시 생성하세요.
- 작성자 정보는 양식에서 `성명`·`직위`·`소속`·`연락처` 라벨 칸을 찾아 그 오른쪽 칸에 넣습니다. 라벨을 찾지 못하면 검수목록에 알려 줍니다.

## CLI 사용

```bat
pip install -r requirements.txt
```

1. `templates/수입지출내역서_양식.hwpx` — 한글 양식(치환 토큰 포함) 배치
2. `input/장부.xlsx`, `input/연체료목록.xlsx`, `input/환불자목록.xlsx` 배치
3. `config/학기설정.json` — 학기·사업명·연체료 규칙·작성자(`author`) 등 조정
4. 실행:

```bat
python -m src.main
```

출력: `output/` 폴더 (파일 이름은 `{label}_{사업번호}_{사업명}.hwpx`)

## 프로젝트 구조

```
src/           엔진 (장부 파싱, 연체료 계산, hwpx 채우기, OCR)
               sheet_reader.py 엑셀 열 찾기 · rules_config.py 비고 규칙 기본값
               template_layout.py 양식 칸 찾기
web/           FastAPI 웹 앱 + UI 템플릿 (runner.py: 준비→미리보기→생성, preview.py: 미리보기)
config/        CLI용 학기 설정 (웹은 업로드만 사용)
docs/SPEC.md   상세 규칙 명세
examples/      연체료 규정 예시 SVG 등
scripts/       검증 스크립트
```
